Selected research

The following projects highlight recent work on AI systems and agent memory, from long-context serving to memory evolution.

Long-context serving

SPIN ↗

Make sparsity work at the system level.

Sparse attention can reduce the KV state an LLM needs to access. But irregular transfers between GPU and CPU memory can erase those savings. SPIN co-designs sparse-attention execution and hierarchical memory management to turn algorithmic sparsity into more efficient serving.

Unifying Sparse Attention with Hierarchical Memory for Scalable Long-Context LLM Serving ↗

Memory & retrieval

RetroInfer ↗

Treat long-context inference as a storage problem.

As context grows, so does the memory behind inference. RetroInfer brings a vector-storage perspective to this problem, using retrieval to make a large KV state accessible without treating every part of it as equally relevant at every step.

RetroInfer: A Vector-Storage Engine for Scalable Long-Context LLM Inference ↗

Self-evolving agent memory

PrisMem ↗

Improve capabilities, not just an overall score.

Improving one memory capability can hide regressions in another. PrisMem guides evolution along individual capability dimensions, refines specialists using task feedback, and integrates their complementary gains into a unified memory program.

Capability-Driven Self-Evolution of Agent Memory ↗

About

I am a Senior Researcher in the Systems and Networking Research Group at Microsoft Research Asia.

I received my PhD from The Chinese University of Hong Kong in 2023 and visited Simon Fraser University in 2019 and 2023. My research spans machine learning systems and database management systems, with a focus on emerging applications and hardware.

I received the 2021 ACM SIGMOD Research Highlight Award. Dash and APEX were also selected among the Most Influential ArXiv (Databases) Papers (top 30 per year).
